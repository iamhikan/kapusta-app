# Капуста — Mini App

Страница Mini App бота семейных финансов «Капуста» в Telegram. Здесь только код страницы: данных, токенов и адресов
нет. Цифры приходят с API на домашнем Маке, и только на подписанный вход из Telegram (`initData`) людей из списка
семьи. Адрес API бот передаёт в ссылке кнопки (`?api=…`).

- `index.html`, `style.css`, `js/` — ES-модули без сборки, графики — свой SVG, тема — цвета Telegram.
- Тесты вида: `node --test`.
